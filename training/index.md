# AeroVision - Training Index

## General Description

The `training/` folder is reserved for AeroVision training, dataset preparation, notebook, artifact, and experiment-import utilities.

According to `../docs/`, training is performed outside the running web application in free cloud notebook environments such as Kaggle Notebook or Google Colab. This folder may later contain scripts, notebooks, configs, dataset split helpers, model-card schemas, and import utilities. The web UI and backend must not launch model training.
